# Buổi 01 – Đệ quy

Họ tên: Lê Đức Vinh · MSV: 10125331

## Bài đã làm
- Bài 1: Sinh ngẫu nhiên 1000 số tự nhiên, lưu vào mảng, tìm số lớn nhất và nhỏ nhất
- Bài 2: FizzBuzz
- Bài 3: Đảo ngược chuỗi
- Bài 4: Sắp xếp mảng tăng dần
- Bài 5: Tìm số Fibonacci thứ n (dãy tính từ F(1) = 0, F(2) = 1)

## Cách chạy
```
dotnet run --project Buoi01_DeQuy
```

## Kết quả chạy

Mảng sinh ngẫu nhiên nên mỗi lần chạy cho số liệu khác nhau.
