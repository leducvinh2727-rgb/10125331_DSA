# Buổi 02 – Danh sách

Họ tên: Lê Đức Vinh · MSV: 10125331

## Bài đã làm
- Bài 1: Tháp Hà Nội (đệ quy), đo thời gian thực thi
- Bài 2: Tìm kiếm nhị phân bằng đệ quy
- Bài 3: Sắp xếp nổi bọt (Bubble Sort) trên mảng số thực
- Bài 4: Kiểm tra số nguyên tố
- Bài 5: Tìm số Fibonacci thứ n bằng vòng lặp
- Bài 6: Liệt kê các số hoàn hảo nhỏ hơn n

## Cách chạy
```
dotnet run --project Buoi02_DanhSach
```
